# Лабораторна робота №6
## Робота з відкритим програмним кодом

**Тема:** Сегментація зображень за допомогою Segment Anything Model (SAM).
**Мета роботи:** Ознайомитися з відкритим програмним кодом моделі машинного навчання, запустити готовий алгоритм та проаналізувати результати.
### Наукова стаття
- **Назва:** Segment Anything
- **Автори:** Alexander Kirillov та інші
- **Рік:** 2023
- **Стаття:** https://arxiv.org/abs/2304.02643
- **Офіційний GitHub:** https://github.com/facebookresearch/segment-anything
### Опис роботи
У лабораторній роботі я використала модель SAM ViT-B для сегментації фотографії двох котів. Модель працювала на процесорі (CPU).
Спочатку я перевірила сегментацію за однією точкою, потім використала кілька точок і прямокутну рамку.
Найвища прогнозована оцінка маски становила 0.956. Проте деякі контури об'єкта залишилися неточними.
### Використані технології
Python 3.12, PyTorch, Segment Anything, OpenCV, NumPy, Matplotlib та Jupyter Notebook.
### Запуск
1. Встановити необхідні бібліотеки:
```bash
pip install "torch==2.15.0" "torchvision==0.29.2" "numpy==1.26.4" "opencv-python==4.10.0.84" "matplotlib==3.8.4" "segment-anything==1.0"
```
2. Завантажити ваги SAM ViT-B за посиланням:
https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth
3. Розмістити файл `sam_vit_b_01ec64.pth` у папці з ноутбуком `lab6.ipynb`.
4. Відкрити `lab6.ipynb` у VS Code або Jupyter Notebook і послідовно запустити комірки.
